## 🎹 Лабораторная работа №1: Синтез и Фурье-анализ

### 1. Исходные данные
**Формула сигнала:**
$$\Large s(t) = \sum_{i=0}^{n} A_i \cdot \sin(2\pi \cdot h_i \cdot f_0 \cdot t + \phi)$$

| Параметр | x(t) (Виолончель) | y(t) (Контрабас) |
| :--- | :--- | :--- |
| **Амплитуды (A)** | `[1.0, 0.6, 0.4, 0.2]` | `[1.0, 0.7, 0.5]` |
| **Частота (f0)** | `110 Гц` | `55 Гц` |
| **Гармоники (h)** | `[1, 2, 3, 4]` | `[1, 2, 3]` |
| **Фаза (phi)** | `0` | `0` |

*   **N:** 1024 отсчета.
*   **fs:** 8000 Гц.

### 2. Задачи
*   Реализовать **линейную свертку** и **корреляцию** (циклы + БПФ).
*   Реализовать **ДПФ** и **БПФ** (прямое и обратное).
*   Сравнить результаты с библиотекой **NumPy**.
*   Верифицировать теоремы о свертке и корреляции.

## 🎙 Лабораторная работа №3: Анализ речи и шумоподавление

### 1. Общие требования
*   Для пунктов 2, 3: **4 музыкальных файла** различных жанров.
*   Для пунктов 4, 5, 6: **запись собственного голоса**.

### 2. Параметры варианта №10
*   **Тип представления:** Мел-спектрограмма.
*   **Признаки (Self-implemented):** MFCC, Спектральный спад (Spectral Rolloff).
*   **Метрики качества (Self-implemented):** SNR, PESQ.
*   **Модель шумоподавления:** DeepFilterNet2.
*   **Параметры тестирования:** Диапазон SNR **8–24 дБ**, шаг **2 дБ**.

### 3. Этапы выполнения
1.  **Частотно-временной анализ:**
    *   Реализовать алгоритм вычисления **мел-спектрограммы** вручную.
    *   Реализовать вычисление спектрограммы и мел-спектрограммы через библиотеки.
2.  **Извлечение признаков:**
    *   Реализовать вручную: **MFCC** и **Spectral Rolloff**.
    *   Реализовать через библиотеки: центроид, спад, ширина, ZCR, MFCC, цветность.
3.  **Шумоподавление и оценка:**
    *   Написать функцию смешивания голоса и шума по SNR (8–24 дБ, шаг 2).
    *   Реализовать метрики **SNR** и **PESQ** вручную.
    *   Использовать библиотечные метрики: **SNR, SDR, SI-SDR, PESQ, NISQA, DNSMOS**.
    *   Применить **DeepFilterNet2** для очистки зашумленных файлов и провести повторную оценку.
4.  **Отчет:** Графики, таблицы сравнения (объективная vs субъективная оценка), выводы.
