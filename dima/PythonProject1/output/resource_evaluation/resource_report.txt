2. ОБРАБОТКА ФАЙЛОВ:
   • original: 5.00с, RAM: 305.3MB, Длительность аудио: 2.1с

3. РЕКОМЕНДАЦИИ:
   • Минимальные требования: 4GB RAM, 2GB на диске
   • Для CPU: используйте Whisper 'tiny' вместо 'base' (экономия 70% памяти)
   • Для GPU: VRAM >= 2GB для комфортной работы
   • Без GPU: время обработки увеличивается в 5-10 раз
   • Кэширование моделей: первый запуск самый долгий
