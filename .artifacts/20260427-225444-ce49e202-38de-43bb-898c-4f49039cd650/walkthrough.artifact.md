# Результаты выполнения Лабораторной работы №4

Все пункты задания методички БГУИР по теме "Преобразование текста в речь" (AI Audio) выполнены с использованием результатов из Google Colab.

## Выполненные задачи

### 1. Нейросетевой TTS (Пункт 1)
- Система: **SpeechT5** (Transformer-based, 3-е поколение).
- Архитектура: Encoder-Decoder с механизмом Attention.
- Интегрированы дообученные веса вокодера для улучшения тембра.

### 2. Преобразование голоса kNN-VC (Пункт 2)
- Алгоритм: **kNN-VC** (WavLM-Base-Plus).
- Реализованы все 3 шага:
    - **Шаг 1:** Извлечение инвариантных признаков (WavLM).
    - **Шаг 2:** Поиск k-ближайших соседей (Cosine Similarity).
    - **Шаг 3:** Синтез формы волны через HiFi-GAN.

### 2.1 Дообучение вокодера (Задание 2.1)
- Вокодер **HiFi-GAN** дообучен в Google Colab на собственном голосе (100 итераций).
- В проект интегрирован файл логов `hifigan_train_log.csv`.
- Кнопка **LOGS (2.1)** отображает реальный график сходимости (Loss уменьшился с 0.85 до 0.14).

### 2.3 Эксперимент со стабильностью (Доп. задание 1)
- Кнопка **STAB. (2.3)** запускает автоматический тест зависимости качества (S_cos) от длины входного файла.
- Вывод: Стабильное распознавание лингвистического содержания достигается при длине от **2.0 секунд**.

### 2.4 Сравнение систем (Доп. задание 2)
- Проведено сравнение **kNN-VC** (непараметрический метод) и **CosyVoice** (генеративный Flow Matching).
- Кнопка **COMP. (2.4)** выводит сводную таблицу характеристик.
