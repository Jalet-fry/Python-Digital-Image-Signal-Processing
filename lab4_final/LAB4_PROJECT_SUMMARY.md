# 🎙️ Лабораторная работа №4: Искусственный интеллект в обработке аудио

Этот документ описывает структуру и работу проекта по 4-й лабораторной работе. Используй его для анализа кода другими нейросетями или для подготовки отчета.

---

## 📂 Структура проекта (Core Files)

Все важные файлы продублированы в папку `lab4_final/` для удобства анализа:

### 🧠 Исходный код твоего проекта (`lab4_final/project_files/`)
- **`lab4_logic.py`**: Главный файл с ИИ-логикой (ASR, TTS, FFT-фильтр).
- **`lab4_ai.py`**: Интерактивная оболочка (GUI контроллер).
- **`lab4_view.py`**: Визуальные элементы интерфейса.
- **`main.py`**: Точка входа в приложение.
- **`requirements_lab4.txt`**: Список зависимостей.

### 🎓 Файлы-образцы (`lab4_final/reference_files/`)
*Копии из PythonProject1 для сравнения:*
- **`task1_tts_coqui.py`**: Пример TTS на базе Coqui.
- **`task2_vc_yourtts.py`**: Пример Voice Conversion на базе YourTTS.
- **`evaluate_resources_ref.py`**: Пример замера ресурсов.
- **`test_minimal_length_ref.py`**: Пример эксперимента с длиной.

## 🧪 Сценарии тестирования (lab4_final/)
*Папка со скриптами, которые выполняют конкретные пункты задания для отчета.*

1. **`task1_tts.py`**: Выполняет Задание 1. Синтезирует введённый текст, копируя голос из файла-образца.
2. **`task2_vc.py`**: Выполняет Задание 2. Берет аудио одного человека и переозвучивает его голосом другого.
3. **`evaluate_resources.py`**: Выполняет Задание 2.2. Замеряет нагрузку на процессор, потребление RAM и время работы. Результат в `resource_evaluation.json`.
4. **`test_minimal_length.py`**: Выполняет Задание 2.3. Режет аудио на куски (0.5с, 1с, 2с...) и проверяет, с какой длины ИИ начинает стабильно узнавать голос.

## 🛠️ Технический стек (Requirements)
- **`requirements_lab4.txt`**: Список всех нейросетевых библиотек.
  - `openai-whisper`: Распознавание речи.
  - `torch` & `torchaudio`: База для работы нейросетей на CPU.
  - `transformers`: Модель SpeechT5 для клонирования голоса.
  - `librosa` & `scipy`: Математика и обработка сигналов (FFT, фильтры).

## 🚀 Как это работает (Workflow)

1. **Инициализация**: При запуске `make lab4` загружаются веса моделей (около 1 ГБ в RAM).
2. **Задание 1 (TTS)**: 
   Текст ➔ [SpeechT5] ➔ [Твой X-Vector (Тембр)] ➔ Аудио файл.
3. **Задание 2 (VC)**: 
   Голос А ➔ [Whisper] ➔ Текст ➔ [Silero] ➔ Голос Робота ➔ [FFT Filter + Тембр Голоса Б] ➔ Голос Б.
