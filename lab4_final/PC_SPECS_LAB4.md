# Характеристики ноутбука для лабораторной работы №4

## Системная информация
- **ОС**: Windows 11 Домашняя
- **Производитель**: Micro-Star International Co., Ltd.
- **Модель**: Modern 14 C5M
- **BIOS**: E14JKAMS.108 (16.05.2023)

## Процессор
- **Модель**: AMD Ryzen 5 5625U with Radeon Graphics
- **Тактовая частота**: 2301 МГц (базовая)
- **Ядра**: 6
- **Потоки**: 12
- **Архитектура**: Zen 3 (Barcelo)

## Оперативная память
- **Общая**: 15 751 МБ (~15.7 ГБ)
- **Доступно при проверке**: 4 963 МБ (~4.8 ГБ)
- **Формат**: DDR4 (предположительно)

## Графический процессор (GPU)
- **Тип**: Встроенный (iGPU)
- **Модель**: AMD Radeon Graphics (в составе Ryzen 5 5625U)
- **CUDA**: Отсутствует (NVIDIA GPU не обнаружен)
- **Вывод команды nvidia-smi**: CommandNotFoundException

## Виртуализация
- **Hyper-V**: Обнаружен
- **Virtualization-based security**: Запущена
- **Hypervisor enforced Code Integrity**: Включена

## Сетевые адаптеры
- **Wi-Fi**: RZ608 Wi-Fi 6E 80MHz
- **Виртуальные**: VirtualBox Host-Only, WireGuard (hide.me)

## Заключение для лабораторной работы
- Все AI-модели будут работать **только на CPU**
- Ожидаемое время загрузки моделей: 2-3 минуты
- Рекомендуется запускать задачи по отдельности (не через GUI)
- При нехватке RAM использовать Google Colab (см. COLAB_GUIDE.md)
