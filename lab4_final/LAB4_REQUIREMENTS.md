# Лабораторная работа №4: Преобразование текста в речь

## 1. Цель работы
Изучение принципов работы современных систем синтеза речи и приобретение навыков работы с высокоуровневыми нейросетевыми архитектурами (CosyVoice3, kNN-VC) для решения задач синтеза и клонирования голоса.

## 2. Основные требования

### 2.1. Синтез речи (TTS)
- Использовать проект **CosyVoice3** (или аналог).
- Озвучить произвольный текст.
- Оценить полученные результаты (качество, естественность).

### 2.2. Преобразование голоса (Voice Conversion - VC)
- Использовать проект **kNN-VC** (или аналог).
- Сконвертировать собственный голос в голос другого диктора.
- **Дообучение вокодера**: Выполнить дообучение вокодера (рекомендуется Google Colab).
- **Оценка ресурсов**: Оценить работу метода в условиях ограниченных ресурсов (CPU-only).

### 2.3. Дополнительные задания
- **Минимальная длина**: Установить минимальную длину входного файла для качественного преобразования.
- **Сравнение**: Сравнить CosyVoice3 (Zero-Shot) и kNN-VC по качеству и сложности.

## 3. Ограничения оборудования (согласно PC_SPECS_LAB4.md)
- **CPU**: AMD Ryzen 5 5625U (6 ядер, 12 потоков).
- **GPU**: Отсутствует (только встроенная графика, нет CUDA).
- **RAM**: ~16 ГБ (~5 ГБ доступно).
- **Режим работы**: CPU-only. Ожидаемое время загрузки моделей: 2-3 минуты.

## 4. Ожидаемый результат
- Исходный код реализации.
- Аудиофайлы (исходные и синтезированные).
- Отчет с выводами и ответами на контрольные вопросы.
